# Currículo em HTML

Este arquivo contém um modelo profissional de currículo desenvolvido em HTML5 e CSS3 modernos.

## Como editar:
1. Extraia o conteúdo deste arquivo ZIP.
2. Abra o arquivo `index.html` em qualquer editor de texto (como VS Code, Sublime Text ou Bloco de Notas).
3. Altere as informações pessoais, experiências e habilidades conforme necessário.
4. Salve o arquivo e abra-o em qualquer navegador web para visualizar o resultado.
